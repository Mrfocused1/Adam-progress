**New files:**
- `assets/lib/supabase.js` — creates and exports the shared Supabase browser client (URL + publishable key).
- `assets/lib/schema.js` — exports `CONTENT_SCHEMA` (declarative section/field/list definitions used to render the admin) and `DEFAULT_CONTENT` (the seed mirroring the current site). Pure data, no DOM/network.

- `assets/content.js` — ES module run on the public site: fetch document, apply scalars + render lists, reveal page, then call `window.initSite()`.
- `admin.html` — admin login + dashboard shell.
- `assets/admin.js` — ES module: OTP auth, schema-driven editor, list add/remove/reorder, media upload, save.
- `assets/admin.css` — admin styling (dark, on-brand).
- `tests/lib.test.mjs` — unit tests for `apply.js`, `schema.js`, `render.js`.

**Modified files:**
- `index.html` — add anti-flash head snippet; add `data-edit` attributes to scalar elements; add `id`/marker hooks to list containers; load `assets/content.js` (module) before `app.js`.
- `app.js` — wrap all top-level interaction code into idempotent `window.initSite()`; self-init only when content bootstrap is absent.

## Conventions

- `data-edit="hero.headline"` marks a scalar element. The path is dotted into the content document. Behavior by element:
  - default → set `textContent`
  - element also has `data-edit-attr="src"` (or `href`) → set that attribute instead
  - element also has `data-edit-html` → set `innerHTML` (for fields that contain markup, e.g. multi-line)
- List containers carry `data-list="feed"` (etc.); `content.js` replaces their children with rendered items when data is present.
- Render functions return **strings**; containers are filled via `innerHTML` once per load (acceptable: thumbnails only, no live iframes until clicked).

```js
// Pure path + escaping helpers. No DOM, no network.
export function getByPath(obj, path) {
  return path.split('.').reduce((o, k) => (o == null ? o : o[k]), obj);
}
export function setByPath(obj, path, value) {
  const keys = path.split('.');
  const last = keys.pop();
  let cur = obj;
  for (const k of keys) { if (typeof cur[k] !== 'object' || cur[k] == null) cur[k] = {}; cur = cur[k]; }
  cur[last] = value;
  return obj;
}
export function escapeHtml(s) {
  return String(s ?? '')
    .replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;').replace(/'/g, '&#39;');
}
```

```js
function applyLists(data) {

    const items = data[key];
```

```js
async function uploadFile(file, section) {

    } catch (e) { status.textContent = 'Upload failed: ' + e.message; }
  });
  wrap.append(preview, url, file, status);
  return wrap;
}
```
